# Observability

Generated by `cargo run --bin curl-audit-traceability`. Run it with
`--check` to compare this file against the tree; a difference, a gap in either
direction, an unresolved locator or a dangling pointer fails the run. Do not
edit this file by hand. Rationale lives in `refactor/docs/DECISION-LOG.md`.

What the vendored oracle already provides and the port reuses, what this project
adds on top of it, and every place a value the oracle writes to a diagnostic
surface is a credential. **97 reused surface(s)** across **11 element(s)**,
**5 added element(s)**, **18 sink(s)** and **17 declared disclosure(s)**.

Reuse is verified rather than claimed: every reused surface is read at the tag
and must still carry the token that names it, so a stale line number fails the
run. The sensitive inventory follows data flow rather than counting emitters,
which is the only way it can be complete - the four line protocols never call
the emitter themselves, they call an exported wrapper, and **89 call site(s)**
of that wrapper are discovered mechanically across their four files. **17** of
those match a declared disclosure shape and each one is declared below; a call
site added upstream changes a frozen count and fails the run whether or not
anyone remembered to write it down.

Nothing added here changes a byte of the reused surfaces. No new command-line
flag, no new library option, no change to the default feature set: the added
instrumentation is compiled in unconditionally and is a complete no-op with no
subscriber installed, which is what keeps the differential byte comparison
honest. Every network-exposed element lives in the verification tree, whose
harness runners are the only long-running processes here for which such an
endpoint means anything.
