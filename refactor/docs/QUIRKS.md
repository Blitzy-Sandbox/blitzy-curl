# Quirks and Hazards

Generated by `cargo run --bin curl-audit-traceability`. Run it with
`--check` to compare this file against the tree; a difference, a gap in either
direction, an unresolved locator or a dangling pointer fails the run. Do not
edit this file by hand. Rationale lives in `refactor/docs/DECISION-LOG.md`.

Every hazard the vendored oracle carries that the port has to answer for, with
the verdict the project holds, the crate that owns it and the verification that
proves the verdict. **376 hazard(s)**: **298** reproduced bug for bug, **64**
substituted with an identical observable outcome, **9** diverging and therefore
carrying a divergence-allowlist entry, and **5** belonging to a platform the
matrix excludes. `Status` is `obligation` where the named verification is not
yet written and `verified` only where an artifact exists. Upstream's own record
of known issues is `original/docs/KNOWN_BUGS.md`; this file records what the
port does about the hazards, not a second copy of that record.

Completeness is a gate rather than a claim. **91 oracle path(s)** are declared
reviewed, each with a frozen row count, and the discovery pass finds **40
annotation site(s)** across them - the markers upstream writes where it knows a
behaviour is sharp. **13** of those sites fall inside a row above; the remaining
**27** carry a written disposition below. A site with neither, a disposition
naming a line that no longer carries an annotation, and a row whose path is not
declared reviewed each fail the run.
